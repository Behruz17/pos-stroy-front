# Корректировки остатков товаров

## Обзор
Модуль корректировок остатков позволяет прямое изменение количества товаров на складе без создания документов поступления или списания. Идеально подходит для инвентаризации и исправления ошибок.

## Доступ к модулю
- **Путь в меню**: Товары → Корректировки остатков
- **URL**: `/stock-adjustments`
- **Права доступа**: Требуется аутентификация

## Основные функции

### 1. Создание корректировки
1. **Выбор товара**: 
   - Используйте выпадающий список для поиска товара
   - Показывается текущий остаток товара
   - Цветовая индикация остатка (красный ≤ 10, желтый ≤ 50, зеленый > 50)

2. **Указание нового остатка**:
   - Введите новое количество товара
   - Система покажет предпросмотр корректировки
   - Зеленый цвет - увеличение, красный - уменьшение

3. **Причина корректировки**:
   - Обязательное поле для объяснения причины
   - Примеры: "Инвентаризация - выявлена недостача"
   - Максимум 500 символов

### 2. Просмотр истории
- **Таблица корректировок**: Показывает все изменения остатков
- **Фильтры**: Поиск по товару, причине, пользователю
- **Фильтр по датам**: Выбор периода для просмотра

### 3. Управление записями
- **Удаление**: Возможность удалить корректировку (с подтверждением)
- **Сортировка**: По дате, товару, размеру корректировки

## Логика работы

### Для обычных товаров (type='simple'):
- Прямое изменение остатка в таблице `stock`
- Создание записи о корректировке в `stock_adjustments`

### Для партионных товаров (type='batch'):
- **Увеличение**: Создается новая партия с кодом `ADJUST-{product_id}-{timestamp}`
- **Уменьшение**: Списание по FIFO из самых старых партий

## Валидация

### Обязательные поля:
- ✅ Товар (product_id)
- ✅ Новый остаток (new_quantity) 
- ✅ Причина (reason)

### Ограничения:
- ❌ Новый остаток не может быть отрицательным
- ❌ Новый остаток не может равняться текущему (нет изменений)

## Примеры использования

### Инвентаризация - недостача:
```
Товар: Цемент М500
Текущий остаток: 100
Новый остаток: 95
Причина: Инвентаризация - выявлена недостача при пересчете
Результат: -5 единиц
```

### Инвентаризация - излишек:
```
Товар: Кирпич красный
Текущий остаток: 200
Новый остаток: 215
Причина: Инвентаризация - выявлен излишек товара
Результат: +15 единиц
```

### Исправление ошибки:
```
Товар: Краска белая
Текущий остаток: 45
Новый остаток: 50
Причина: Исправление ошибки при предыдущем поступлении
Результат: +5 единиц
```

## Аудит и безопасность

### Записываемые данные:
- 📅 Дата и время корректировки
- 👤 Пользователь, создавший корректировку
- 📦 Товар и его количество до/после
- 📝 Причина изменения
- 🔄 Размер корректировки

### Безопасность:
- 🔒 Требуется аутентификация
- 👀 Все действия записываются в лог
- 🗑️ Мягкое удаление (status = 0)

## Интеграция с системой

### Влияние на модули:
- **Товары**: Обновление остатка в реальном времени
- **Продажи**: Актуальные остатки при продаже
- **Отчеты**: Корректировки не создают документов, но влияют на остатки

### Обратная совместимость:
- ✅ Существующие функции работают без изменений
- ✅ Продажи и поступления используют ту же логику
- ✅ Отчеты учитывают скорректированные остатки

## Важные моменты

1. **Не создает документы**: Корректировки не генерируют приходы/списания
2. **Мгновенное применение**: Изменения применяются немедленно
3. **Аудитный след**: Все изменения отслеживаются с указанием причины
4. **FIFO для партий**: При уменьшении списание идет из старых партий

## Рекомендации

### Когда использовать корректировки:
- ✅ Инвентаризация (выявление недостач/излишков)
- ✅ Исправление ошибок ввода
- ✅ Пересчет после пересортицы
- ✅ Списание порчи/боя

### Когда не использовать:
- ❌ Регулярное поступление товаров (используйте "Поступления")
- ❌ Списание для продажи (используйте "Продажи")
- ❌ Перемещение между складами (если есть такая функция)
