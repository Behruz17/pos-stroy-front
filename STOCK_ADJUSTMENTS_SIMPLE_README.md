# Корректировки остатков товаров (упрощенная версия)

## Обзор
Простой и удобный способ изменения остатков товаров прямо со страницы товаров. Идеально подходит для быстрой инвентаризации и исправления ошибок.

## Как использовать

### 1. Перейдите на страницу товаров
- **Путь в меню**: Товары → Список
- **URL**: `/products`

### 2. Найдите нужный товар
Используйте поиск для быстрого нахождения товара:
- Поиск по названию
- Поиск по производителю  
- Поиск по артикулу

### 3. Нажмите кнопку изменения остатка
В колонке "Действия" напротив каждого товара есть кнопка 📦 "Изменить остаток"

### 4. В модальном окне:
- **Название товара**: отображается выбранное название
- **Текущий остаток**: показано текущее количество на складе
- **Новый остаток**: введите новое количество товара
- **Предпросмотр корректировки**: автоматически показывается разница

### 5. Сохраните изменения
Нажмите кнопку "Сохранить" для применения корректировки

## Особенности модального окна

### ✨ Умный предпросмотр
```
Текущий остаток: 100
Новый остаток: 95

Корректировка: -5
```

### 🎨 Цветовая индикация
- 🟢 **Зеленый**: увеличение остатка (+5)
- 🔴 **Красный**: уменьшение остатка (-5)

### ✅ Валидация
- Остаток не может быть отрицательным
- Нельзя сохранить без изменений
- Автоматическая проверка перед сохранением

## Примеры использования

### Инвентаризация - недостача:
1. Найти товар "Цемент М500"
2. Нажать 📦
3. Увидеть: Текущий остаток: 100
4. Ввести: Новый остаток: 95  
5. Сохранить → Корректировка: -5

### Инвентаризация - излишек:
1. Найти товар "Кирпич красный"
2. Нажать 📦
3. Увидеть: Текущий остаток: 200
4. Ввести: Новый остаток: 215
5. Сохранить → Корректировка: +15

### Исправление ошибки:
1. Найти товар с неправильным остатком
2. Нажать 📦
3. Ввести корректное значение
4. Сохранить

## Логика работы

### Для обычных товаров (type='simple'):
- Прямое изменение остатка в таблице `stock`
- Создание записи о корректировке в `stock_adjustments`

### Для партионных товаров (type='batch'):
- **Увеличение**: Создается новая партия с кодом `ADJUST-{product_id}-{timestamp}`
- **Уменьшение**: Списание по FIFO из самых старых партий

## Безопасность и аудит

### 📋 Записываемые данные:
- 📅 Дата и время корректировки
- 👤 Пользователь, создавший корректировку
- 📦 Товар и его количество до/после
- 📝 Причина: "Корректировка остатка со страницы товаров"
- 🔄 Размер корректировки

### 🔒 Безопасность:
- Требуется аутентификация
- Все действия записываются в лог
- Мягкое удаление (status = 0)

### Обратная совместимость:
- ✅ Существующие функции работают без изменений

## Рекомендации по использованию

### ✅ Когда использовать:
- Инвентаризация (выявление недостач/излишков)
- Исправление ошибок ввода
- Пересчет после пересортицы
- Списание порчи/боя
